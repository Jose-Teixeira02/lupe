# Contributing to Lupe

Thanks for your interest! Lupe is a personal project by José Teixeira. Suggestions are very welcome.

## Suggestions and bugs

Open an issue and describe what you saw or would like to see. For a wrong translation or meaning,
include the sentence and the word you pointed at; context is what Lupe uses to decide.

## Code and language packs

Before starting on a large change, open an issue first so we can agree on it. Language packs (a new
language, more words, idioms, "Don't mix up" notes) are the most useful contributions. The format is
in the README under "Adding a language".

Run `scripts/check.sh` before sending a pull request; it must pass.
